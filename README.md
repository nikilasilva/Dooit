# DooIt

DooIt is a simple and modern task management app built with Flutter. It helps users organize and track their daily tasks with features for categorization, scheduling, and productivity analytics.

## Features
- Add, edit, and delete tasks
- Categorize tasks (e.g., Work, Personal, Shopping)
- View tasks by category
- Daily, weekly, and monthly productivity analytics
- Change profile picture, username, and password
- Responsive and clean UI

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/dooit.git
   cd dooit
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Folder Structure
- `lib/` - Main source code
- `assets/` - Images and icons
- `test/` - Widget and unit tests

## Requirements
- Flutter SDK
- Firebase project (for authentication and storage)
